  3. Drop both files above. Nothing changes until you download the new vault.

    Same account
    Two entries belong to one account when they have the same website and the same username. Capital letters in usernames are ignored. Passwords must match exactly.
    Same website
    Subdomains count as one website: www.tiktok.com, tiktok.com and careers.tiktok.com are all tiktok.com. A login saved without a web address uses its name when the name is a domain (and gets it as its web address), or joins an entry with the identical name, username and password. Hosting platforms are not lumped together, so foo.github.io and bar.github.io stay different. This uses the Public Suffix List bundled with this page.
    Exact duplicates
    Same website, username and password. One entry is kept, preferring Bitwarden over Chrome, then the most recently updated. It receives every web address, note, custom field, 2FA code and passkey from the copies.
    Older passwords
    Same username on the same host (www. ignored) but a different password. The current password is chosen in this order: a password that another copy lists as old loses; a password set on a real date wins over passwords that already existed before that date; otherwise the password that Chrome and a dated Bitwarden entry both have wins. An import stamps every item with the import time (shown as "Imported"), so that date only proves the password existed by then. If none of this settles it, nothing is guessed and both entries are kept. The other passwords are saved in the kept entry's password history, so you can still find them in Bitwarden.
    Never merged
    Different 2FA codes, more than one passkey, different subdomains with different passwords, local network addresses such as 192.168.1.1, entries without a username that have different passwords, the same password on different websites, and cases where the current password can't be told apart. These are listed under Kept separately.
    Copied as they are
    Cards, identities, secure notes, SSH keys, organization items, items in the trash and logins without a website. They can't be matched safely, so they go into the new vault unchanged. They're listed under Copied as is.
    Password codes
    The coloured dot and four-letter code are a fingerprint of the password. Same colour and code means same password. Use Show to see the password itself.
